[★P0 correction note: Harvard-Oxford atlas label misalignment]
All ROI-derived values for v41 and earlier versions in this directory were based on an atlas mask that was **shifted by 1 position overall**.
Cause: the label **value** in the Harvard-Oxford atlas NIfTI file = the index of the same-named XML + 1
(XML index 0 = "Left Cerebral White Matter", whereas image value 0 = background).
The old code used the XML index directly as the image value, which resulted in:
  - the "hippocampus mask" (value 8/18) being in fact the **brainstem + right globus pallidus** (40728 mm³)
  - the "amygdala mask" (value 9/19) being in fact the **bilateral hippocampus** (11263 mm³)
  - the "parahippocampal gyrus mask" (cortex 33/34) being in fact the frontal orbital cortex + anterior parahippocampal gyrus
The code has been corrected (`AD-3D-CNN/evaluate/gradcam_roi.py`, with an added anatomical centroid self-check), and the analysis was rerun for
the 144 samples × 5 folds Grad-CAM ROI analysis. All the values below are the **corrected** results.
Correct mapping: hippocampus 9/19, amygdala 10/20, anterior parahippocampal gyrus 34 / posterior 35, lateral ventricle 3/14, brainstem 8.

   Amygdala: (  1.8,  -4.3, -18.0)  ✓ medial/deep temporal lobe

[Note on the normalisation definition]
The "CAM intensity" cited in the main text (Sections 3.3/4.2 and the conclusion) refers throughout to the sample-level mean CAM over in-brain voxels
(cam_mean) definition: correct vs incorrect Mann-Whitney U=1802, p=0.00029, Cliff's δ=0.52;
correct mean 0.1365 vs incorrect 0.0956 (see the "cam_mean" entry in statistical_results.json).
The [CAM intensity (95th percentile…)] section below uses the cam_p95 definition (U=1750,
0.2383 vs 0.1728), and serves only as a robustness reference; do not use it directly as a main-text figure.
