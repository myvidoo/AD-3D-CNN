# --- Deep learning framework ---
# The measured training environment was PyTorch nightly: torch==2.13.0.dev20260418+cu132 (CUDA 13.2).
# Released against the corresponding stable build: same minor version (2.13) and the same CUDA
# generation (13.2), which keeps reproduction as close to the measured environment as a stable
# release allows. This also satisfies MONAI 1.5.2's own requirement (torch>=2.4.1) and supports
# RTX 50-series / Blackwell GPUs (sm_120), which need a CUDA 12.8+ build.
#
# Install with the CUDA wheel index, or pip will resolve to a CPU-only build:
#   pip install torch==2.13.0 --index-url https://download.pytorch.org/whl/cu132
# If your NVIDIA driver predates CUDA 13.2, use the same torch version on the cu130 build:
#   pip install torch==2.13.0 --index-url https://download.pytorch.org/whl/cu130
